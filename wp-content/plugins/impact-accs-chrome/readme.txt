=== Impact.accs Chrome for Elementor ===
Version: 2.0.0

Плагин воссоздаёт 1:1 с https://cu59725-wordpress-9vuvh.tw1.ru/:
- хедер (Sound: locked, навигация, Request access)
- футer (колонки Menu/Company/Features/Socials, Privacy/Terms/DPA)
- красные рамки с логотипом при скролле
- кастомный скроллбар справа
- блок REQUEST ACCESS с формой

HTML и CSS взяты напрямую из оригинального сайта (index.html + _next/static/chunks/*.css).

== Установка ==
1. Загрузите impact-accs-chrome.zip в WordPress → Плагины → Добавить.
2. Активируйте.
3. Нужны Hello Elementor + Elementor.
4. Контент страниц собирайте в Elementor — хром подключится автоматически.

== Шорткод ==
[impact_request_access] — только блок Request Access (из оригинального footer).

== Elementor ==
Виджет «Impact Request Access».
